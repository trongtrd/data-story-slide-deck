# `ANTI-VIS-002` — Falling for AI Novelty Bias and Inserting Static Raster Chart Images

## 1. Statement
Do not accept exotic, unfamiliar chart types suggested by AI (such as radar charts, bubble charts, stream graphs, or complex multi-axis hybrids) when a familiar workhorse chart communicates the point faster, never pick a form for novelty, variety or attention (`CONF-007`), and never insert static raster images (`.png` / `.jpg`) generated by chat models as the final chart in an editable `.pptx` deliverable.

## 2. Why It Matters
LLMs frequently exhibit **novelty bias**—proposing intricate chart types that look sophisticated in data-science portfolios but stall executive comprehension. Furthermore, static chart images produced by conversational LLMs frequently contain subtle plotting inaccuracies and lock the human author out of making essential last-mile refinements (adjusting axis bounds, nudging overlapping labels, or matching brand colors).

## 3. Agent Application
- **Block Novelty Bias (`visual-planner`):** Always evaluate whether one of the 6 familiar workhorses (`PRIN-VIS-002`) can show the takeaway before considering any non-standard chart form.
- **Connected dot plot is not novelty (`D-051`):** the two-dot form SWD calls a connected dot plot (often called a dumbbell plot; an arrowhead may show direction) is a Tier 2 form (`PRIN-VIS-007`) when the gap between two series is the message. It is sorted by the gap or a stated order, colours the direction of change, and carries a reading aid (`SRC-SWD-011` §08).
- **Enforce Native Editable Objects (`deck-builder`, `D-008`):** In `.pptx` output mode, compile `slide_spec.yaml` into **native editable PowerPoint charts and shapes** (`python-pptx`) so the user retains 100% control over data values, labels, axes, and colors. (Rendered PNGs may be used internally by `deck-reviewer` at `Checkpoint G4` for visual inspection, but never as the slide content itself.)

## 4. Testable Checks
- **Zero Raster Charts in `.pptx`:** In `.pptx` build mode, 100% of quantitative charts are native `GraphicFrame` chart objects (or native vector shapes for custom slopegraphs/annotations), with zero `.png`/`.jpg` chart embeds.
- **Novelty Rejection Check:** Any proposed radar, bubble, stream or dual-axis chart is automatically replaced with a slopegraph, dot plot, horizontal bar, or `Small Multiples` line chart unless explicitly overridden by the user (radar and bubble via the specialist override; dual-axis never, `D-051`). A connected dot plot passes when it meets the conditions above.

## 5. Good vs. Bad Example
- **Bad:** Pasting a flat PNG screenshot of a ChatGPT-generated radar chart onto a PowerPoint slide—where the y-axis font is tiny, two labels overlap, and the user cannot edit a single number without regenerating the image.
- **Good:** Generating native editable PowerPoint line/slopegraph objects from `slide_spec.yaml` so the user can click any label, line, or axis in PowerPoint and tweak it in seconds.
